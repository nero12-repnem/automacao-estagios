# Automação de Processamento de Estágios

Projeto de automação para identificar, processar e organizar informações relacionadas a estágios não obrigatórios.

## Status
**Em desenvolvimento.**

## Objetivo
Automatizar a leitura de mensagens e documentos de estágio, reduzindo tarefas repetitivas e estruturando as informações para consulta.

## Escopo
- Identificação de e-mails relevantes
- Processamento de documentos PDF
- Tratamento de documentos disponibilizados por links
- Extração de informações estruturadas
- Registro dos resultados em planilhas
- Filtros para documentos de estágios não obrigatórios

## Integrações planejadas
- Gmail
- Google Drive
- Google Sheets

## Privacidade
O repositório não deve conter e-mails reais, PDFs de estudantes, dados pessoais, credenciais ou tokens. Exemplos públicos devem utilizar dados fictícios.
